# VIETSAFE Standards — Hệ thống Tra cứu Tiêu chuẩn PCCC

Webapp tra cứu tiêu chuẩn phòng cháy chữa cháy — Công ty Cổ Phần VIETSAFE E&C

## Tech Stack
- Next.js 14 (App Router)
- NextAuth.js (Authentication)
- Upstash Redis (Storage)
- BM25 Search (Vietnamese)
- Claude Haiku (AI Q&A)
- Tailwind CSS (Styling)

## Setup
```bash
npm install
cp .env.example .env.local
# Edit .env.local with real credentials
npm run dev
```

## Deploy
Push to main → Vercel auto-deploy
